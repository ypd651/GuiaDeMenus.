# 🌎 Menús Internacionales - Práctica de Git y GitHub

## 📖 Descripción

Este proyecto fue desarrollado con el objetivo de fortalecer mis habilidades en el uso de **Git y GitHub**, aplicando un flujo de trabajo basado en ramas, commits y fusiones.

Como contenido del proyecto se crearon diferentes **menús representativos de varios países**, donde cada cambio fue realizado siguiendo buenas prácticas de control de versiones.

El propósito principal no fue el desarrollo de una aplicación compleja, sino demostrar el manejo correcto de herramientas de versionamiento utilizadas en entornos profesionales.

---

## 🎯 Objetivos

- Aprender el flujo de trabajo con Git.
- Crear y administrar ramas (Branches).
- Realizar commits con mensajes descriptivos.
- Fusionar ramas mediante `merge`.
- Resolver posibles conflictos.
- Mantener un historial organizado de cambios.
- Publicar el proyecto en GitHub.

## 🌱 Flujo de trabajo

Durante el desarrollo se siguió un flujo similar al utilizado en equipos de desarrollo:

1. Creación de la rama principal (`main`).
2. Creación de ramas para nuevas funcionalidades.
3. Desarrollo de cambios en cada rama.
4. Realización de commits descriptivos.
5. Integración mediante `merge`.
6. Publicación del proyecto en GitHub.

## 💻 Ejemplos de comandos utilizados

```bash
git init

git branch menu-colombia

git checkout menu-colombia

git add .

git commit -m "Agregar menú típico de Colombia"

git checkout main

git merge menu-colombia

git push origin main
```
